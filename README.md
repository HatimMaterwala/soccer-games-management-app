# Northside Youth Soccer (prototype)

Clickable prototype of the kids soccer league website for Mohamed.

Open `index.html` in any browser (double-click it). No install or server needed.

Pages: Home, Schedule, Roster, Payments (coach password: `coach`), Player Cards.

Everything is sample data: league name, teams, coaches, players, dates and fees are placeholders.
Payment changes reset on reload. A real version would add a free database (e.g. Supabase) and coach logins.
